## Landie - Property Management System

Landie is a comprehensive property management system designed to provide a centralized hub for all things property-related. This system streamlines property management tasks, making it easier for property managers, landlords, and tenants to manage and access property information.

### Features

- **Property Listings**: Easily add, edit, and view property listings.
- **Tenant Management**: Manage tenant information and lease agreements.
- **Maintenance Requests**: Submit and track maintenance requests.
- **Financial Tracking**: Keep track of rent payments and expenses.
- **Reports and Analytics**: Generate detailed reports on property performance.

### Getting Started

To get started with Landie, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/bagoviggo/landie.git
    ```
2. **Install dependencies**:
    ```bash
    cd landie
    npm install
    ```
3. **Run the development server**:
    ```bash
    npm run dev
    ```
